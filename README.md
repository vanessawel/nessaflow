# NessaFlow

Vanessas ADHS-freundliche App für Aufgaben, Routinen und Gesundheit.

- **Heute:** maximal 3 Aufgaben, Mini-Schritte, Fokus-Timer, aktuelle Routine und ein 10-Sekunden-Check-in
- **Inbox:** Gedanken schnell notieren und später sortieren
- **Routinen:** Morgen- und Abendroutine, frei bearbeitbar
- **Woche:** Rückblick auf Schlaf, Aufgaben, Wasser, Bewegung, Medikamente und Stimmung

Die App läuft als Web-App (PWA) über GitHub Pages und funktioniert offline. Alle Daten bleiben auf dem Gerät; im Bereich „Woche“ gibt es eine Sicherung als Datei.

## Aufs iPhone holen

1. Die Seite in **Safari** öffnen.
2. Unten auf das Teilen-Symbol tippen.
3. **„Zum Home-Bildschirm“** wählen und bestätigen.
